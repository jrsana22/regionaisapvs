# Regionais APVS — sites

Sites das regionais APVS, uma pasta por regional.

| Pasta | Regional | Origem |
|---|---|---|
| `topiguacudois/` → https://topiguacudois.regionaisapvs.com.br | APVS Brasil — Regional Top Iguaçu 2 | cópia fiel do site publicado em https://regionaltopiguacudois.lovable.app (05/10/2026), sem edição |
| `pracadabandeiradois/` → https://pracadabandeiradois.regionalapvs.com.br | APVS Brasil — Praça da Bandeira 2 | cópia fiel do site publicado em https://pracadabandeiradois.lovable.app (10/10/2026), sem edição |
| `california/` → https://california.regionalapvs.com.br | APVS Brasil — Regional California | cópia fiel do site publicado em https://regionalcalifornia.lovable.app (10/10/2026), sem edição |

Cada pasta é um site estático pronto (abrir `index.html` por um servidor web; as páginas internas ficam em `contato/`, `servicos/`, `sobre/`, `privacidade/`, `termos/`).

> ⚠ A cópia é a versão **publicada/compilada** do Lovable. Para editar o conteúdo, o ideal é conectar o projeto do Lovable a este repositório (Lovable → GitHub → Connect) e trazer o código-fonte.
